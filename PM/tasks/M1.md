## Scope
Szkielet aplikacji: Python/Textual, `flowtui init`, config, 4 panele TUI, limit tracking, startup.

## Tasks

Stwórz strukturę pakietu Python: `pyproject.toml` z dependencies (textual>=0.50, pydantic>=2.0, watchdog>=4.0, filelock>=3.0, click>=8.0) i dev deps (pytest, pytest-asyncio, pytest-cov). Entry point `flowtui = "flowtui.cli:main"`. Puste `__init__.py` we wszystkich modułach.

### T1.10: Direct mode + Session mode
Direct mode — komendy TUI: `cc "<prompt>"`, `codex "<prompt>"`, `gemini "<prompt>"` — bezpośredni subprocess passthrough bez pipeline.
Session mode — `cc` lub `gemini` (bez promptu) → otwiera interaktywną sesję przez PTY embedowane w panelu OUTPUT. Codex = zawsze one-shot (brak sesji).
Zachowanie obu trybów: streaming/PTY do TerminalPanel, logowanie do analytics.jsonl (timestamp, tool, prompt/session, exit_code, wall_time), inkrementacja LIMITS.
Config: ToolConfig z `command: str` i `direct_flags: list[str]`. Domyślne flagi z config.toml.
Status: DONE (direct mode) / TODO (session mode PTY)
