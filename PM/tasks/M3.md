# M3: Automation — Tasks

## Scope
Pełny cykl run, git isolation, retry, circuit breaker, sprint automation, merge.

## Tasks

### T3.1: GitOps
`flowtui/core/git_ops.py` — GitOps: create_branch(name), checkout(branch), checkpoint(msg), rollback(pre_hash), diff_stat() → DiffStat, merge_to(target, source) → MergeResult, current_branch(), has_changes().
Wszystkie operacje przez asyncio.create_subprocess_exec("git", ...). Zapamiętuj pre_hash = git rev-parse HEAD przed invocation.
Status: DONE

### T3.2: TestRunner
`flowtui/core/test_runner.py` — auto-detect test framework z pyproject.toml/package.json/pubspec.yaml. run_tests(project_root) → TestResult(passed, count, output). Jeśli brak test framework → TestResult(passed=None, skipped=True).
Status: DONE

### T3.3: Pełny cykl run_task
`flowtui/core/engine.py` Orchestrator.run_task(task_id) → TaskResult:
1. git create_branch + checkpoint (zapamiętaj pre_hash)
2. update_status → IN_PROGRESS
3. invoke_streaming CC (impl)
4. diff_stat + run_tests
5. invoke CC (review)
6. verify AC (run_tests ponownie)
7. update_status → DONE / BLOCKED
8. write_sprint_context
9. zwróć TaskResult z tabelą raportu
Status: DONE

### T3.4: Retry logic
MAX_RETRY=2. Po FAIL testów: rollback(pre_hash) + retry invoke_streaming. Po 2 FAIL: status BLOCKED. TaskResult zawiera retry_count.
Status: DONE

### T3.5: Circuit breaker
W run_sprint(): licznik consecutive_fails. Po 3 consecutive fails: przerwij sprint, zwróć SprintResult z circuit_breaker=True. Reset licznika po każdym SUCCESS.
Status: DONE

### T3.6: run sprint + sprint summary
Orchestrator.run_sprint() → SprintResult: pobiera wszystkie TODO po priority, wykonuje sekwencyjnie run_task(). Po zakończeniu: generuje sprint summary (tabela: task, status, czas, retry). CC generuje "następne kroki" jako część summary.
Status: DONE

### T3.7: merge command
Orchestrator.merge(task_id=None): dla konkretnego taska lub wszystkich DONE. git checkout develop + git merge --no-ff. CONFLICT → abort + lista konfliktujących plików.
Status: DONE
