### T5.6: Parallel task execution — CC orchestrator
FlowTUI uruchamia wiele tasków jednocześnie gdy CC orchestrator zdecyduje, że można.
Mechanizm: CC analizuje TASK-XXX.md sprint i wskazuje grupy niezależnych tasków (brak overlapping FILES). FlowTUI uruchamia asyncio.gather() dla każdej grupy — wiele subprocess CC/Codex jednocześnie, każdy na osobnym git worktree.
CC orchestrator: wywołanie CC z listą tasków i ich FILES → output: JSON z grupami równoległymi `[[T1, T3], [T2, T4]]`.
Wymagania: git worktree per task, merge strategy po zakończeniu grupy, conflict detection.
Konfiguracja: `[run] parallel = true` w config.toml (domyślnie false).
