# Scenariusze testowe — M3: Automation

| # | Zadanie | Scenariusz (krok po kroku) |
|---|---------|---------------------------|
| 3.1 | Run task (happy path) | 1. Wpisz `run TASK-001` 2. Branch `flowtui/TASK-001` tworzony 3. CC implementuje (streaming) 4. Testy przechodzą 5. Tabela raportu: impl OK, testy OK, review OK, AC OK, DONE |
| 3.2 | Run task (retry) | 1. Wpisz `run TASK-001` (testy failują) 2. Retry automatyczny 3. Po 2 failach: status BLOCKED, tabela z retry count=2 |
| 3.3 | Circuit breaker | 1. Wpisz `run sprint` (co najmniej 3 taski TODO, każdy failuje) 2. Po 3 kolejnych failach: sprint zatrzymany, sprint summary z informacją o circuit breaker |
| 3.4 | Merge | 1. Wpisz `merge TASK-001` (brak konfliktu) 2. Merge do develop OK, raport 3. Wpisz `merge TASK-002` (konflikt) 4. Abort + lista konfliktujących plików |
